# Roadmap

## Phase 1: Fræ Validation

- Define the target user segment and buyer: student, parent, tutor, school, or institution.
- Run structured tests with students and teachers.
- Validate core modes: hint, solution check, reveal.
- Improve unclear-handwriting and retry flows.
- Build consent-aware evaluation methodology.
- Produce Sproti-ready scope, budget, and development plan.

## Phase 2: Product Hardening

- Improve backend test coverage and CI.
- Generate client models from OpenAPI or another shared contract source.
- Harden auth, storage, analytics, and deployment flows.
- Build teacher-facing dashboard prototype.
- Expand model routing and provider comparison.

## Phase 3: Pilot and Research

- Run a controlled pilot with real users and explicit consent.
- Build curated evaluation datasets from pilot data.
- Measure learning outcomes and product trust signals.
- Compare tutoring policies and model behaviors.
- Prepare Sproti application and partner/customer pipeline.
